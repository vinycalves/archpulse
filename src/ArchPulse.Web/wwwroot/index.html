The loop

          
From repository to review, in one scan.

        

      

      

        

          01
          
Discover

          
Reads project references, package dependencies, and Aspire AppHost declarations without requiring a build.

        

        

          02
          
Map

          
Turns the repository into a living graph grouped by domain, application, infrastructure, presentation, and runtime.

        

        

          03
          
Guard

          
Evaluates layer rules, cycles, test references, and forbidden dependencies. Every finding is explainable.

        

        

          04
          
Diff

          
Compare two scans and post the architectural delta on every pull request with the CLI or the API.
